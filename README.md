# Пробуждение монстров

Одиночная пиксельная RPG-стратегия в одном HTML-файле: отряд героев, карта миров,
пошагово-реальное сражение, реликвии, магазин и коллекция бойцов.

Файл игры: **`index.html`** — это ровно тот файл, который ты прислал
(`Пробуждение_монстров_исправлено.html`), переименованный в `index.html`,
чтобы он открывался как сайт. Внутри ничего не менялось.

## Как запустить

Вариант 1 — просто открыть файл в браузере (двойной клик по `index.html`).

Вариант 2 — локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

## Управление

- мышь / тап — выбор пунктов меню, кнопок, клеток карты;
- `Пробел` / `Enter` — авто-расстановка отряда, старт боя, пропуск сообщений;
- `1` / `2` / `3` — скорость боя;
- `P` / `Esc` — пауза;
- `M` — музыка/звук (кнопки в правом верхнем углу).

## Что внутри файла

- `#game-assets` — встроенные base64-ассеты (атласы спрайтов, фоны, иконки);
- `#game-src` — исходник игры (≈8,7 тыс. строк) и шрифт;
- загрузчик — запускает игру, хранит сохранения, а также содержит встроенную
  панель «улучшить игру через ИИ» (обращается к внешнему API по ключу из настроек).

## Заметки

- В предпросмотре внутри iframe браузер может запретить `localStorage`,
  поэтому сохранения там временные; при открытии файла напрямую они работают.
- Размер файла ~5,7 МБ, потому что все картинки и шрифт зашиты внутрь base64.
