## Очередь (по важности)

| № | Задача | Команда/критерий |
|---|---|---|
| 1 | Прогон в настоящем браузере и на телефоне: FPS, тач, ИИ-редактор с песочницей, окно экспорта | Playwright/устройство; `tools/e2e.mjs` сценарии как основа; бюджеты `update` ≤ 3 мс, `draw` ≤ 8 мс |
| 2 | `bakeMap` порциями (`requestIdleCallback`) или в воркере + индикатор | первый вход в мир без фриза ≥ 100 мс; golden карт бит-в-бит |
| 3 | Разбор `dFight` (185), `dShop` (172), `dMsg` (133), `dFx` (127) | `npm run lint` без предупреждений; снимки `npm run shotdiff` 0,000 % |
| 4 | Лимиты кэшей: LRU 64 для `TINTC`, палитра радужного тона 2° | soak 30 мин свободной игры ≤ 5 % после прогрева (сейчас +6–8 %) |
| 5 | Soak-сценарий «пройти 3 мира» (сейчас бот часто застревает на арене) | покрытие экранов `world`/`win`, реликвии редкости ≥ 5 |
| 6 | ИИ-редактор: режим «весь модуль», экспорт истории версий файлом, вынести видео панели из загрузчика (−1,4 МБ) | `tests/unit/editor.test.mjs` расширить |
| 7 | Индикатор «сохранения временные» в самой игре при работе без `localStorage` | тост на экране карты + подсказка про экспорт |
| 8 | Расширить golden до 500 боёв / 1000 карт (как было в PR #3) — осознанной пересъёмкой с записью в `BALANCE.md` | `npm run golden:record` |

## Команды для продолжения

```bash
npm install
npm run check && npm run lint && npm test && npm run fuzz && npm run golden
node --expose-gc tools/soak.mjs --minutes 30 --seed 7
npm run e2e && npm run perf
npm run build:dist   # dist/game.html + dist/SHA256SUMS.txt
```
