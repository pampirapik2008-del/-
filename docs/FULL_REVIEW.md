## 1. Что это за игра

Однопользовательский roguelite-автобаттлер в одном HTML-файле, офлайн, без внешних запросов. Открывается двойным кликом.

**Цикл:** Меню → Выбор 1 из 14 героев → Карта мира (процедурная, 10 миров) → Узлы: бои / события / магазин → Победа над боссом мира → Следующий мир (*2 к силе врагов, *1.5 к наградам) → Финал после 10 миров / Поражение.

Режимы: **Кампания** (10 миров по нарастающей) и **Арена** (бесконечные волны, 3 случайных героя на старте, лавка между волнами, рекорды `CFG.best` / `CFG.arenaBest`).

Каждый имеет: `hp/atk/arm/aspd/spd/rng`, спрайт (`SH/KN/PA/BA/CAT`), масштаб `sc`, и **набор KIT**: пассивка `ab` (cd 5-9с) + ульта `ult`. Примеры: *Колючий корень* (стан 1.5с), *Клинок рассвета* (400% AoE), *Вихрь ударов* (6×90%, неуязвим) и т.д.

### 2.2 Миры — 10 шт.

`taiga → desert → ice → fire → swamp → sky → dead → crystal → chaos → final`. У каждого: `id/n/sub/fy0/amb/wx/big/small/destr/light/decor/patch/el/foes/tA/tB/boss/mus/ui`. Боссы двухфазные (`p1/p2`, `n/n2`): Король слизней, Песчаный владыка, Ледяной король, Магмовый владыка, Трясинный король, Грозовой король, Костяной король, Кристальный король, Король хаоса, Пробудитель.

Тонировка атласов: `tA`/`tM`/`tB` перекрашивают `GREEN_H`/`RED_H` через `recolor()`.

### 2.3 Реликвии — 18 шт., 7 редкостей

Редкости `RAR[0..6]`: Обычная→Секретная, множители `m` 1→9, `um` для апгрейда. Шансы `rollRar(luck, min)` сдвигаются `luck = w*0.7` (+0.6 для сундуков).

Реликвии: `fang/shell/heart/boots/hourglass` (статы `st`) + `blood/thunder/vial/frost/flame/ward/clover/crown/skull/eye/feather/tome/blade` (боевые `p`). Цена `relPrice(r,w) = [8,12,18,28,45,80,140][r] + w*2`. Магазин: 3 уникальные реликвии за раз, реролл `3+2*rr` монет.

### 2.4 Враги и события

`ENEM`: `slime/swamp/red/boss` + по 3 именных в каждом мире. Типы узлов `N[].k`: `boss/tribe/chest/arena/barr/mine/swamp/secret/rand`. Логика `go(n)` / `enter(kind)` / `win()` / `lose()`.

## 3. Системы

- **Карта:** `genMap()` — 6-8 слоёв, 1-4 узла на слой, связи с сортировкой по Y, анти-наложение (76px, 40 итераций), `MAPT` палитры + `bakeMap()` (запекание 609×270: пятна, озёра, дороги, площадки, лес). Кэш `MAPC/MAPK` по `seed:мир`.
- **Арена боя:** `30_arena.js` — `FLD` 96-1122×fy0-440, `CELL=14`, препятствия `PROP` (10 типов + `hp/deb/glow`), покрытия `PATCH` (9, `slow/slip/haz`), освещение/погода/`vnoise`/`rng32`.
- **Бой:** `40_fight.js` (1600 строк) — расстановка `place()`, `unitStep()` 246 строк (движение/удары/кулдауны/статусы `burn/poison/chill/shock/curse/stun/shield/rage`), босс-фазы.
- **Отрисовка:** `50_draw.js` — `dFight/dMap/fightHud/bossBar/hud`, 609×270→1218×540 `AP=2`.
- **UI:** `15_ui.js` — `rframe/rfx/panel/btn/toast/Fly/Seq/Parts`. `65_screens.js` — все экраны `S` (`menu/pick/map/msg/shop/world/prep/fight/win/lose/codex/settings/collection`).
- **Аудио:** `70_audio.js` (WebAudio, синтез + музыка по мирам).
- **Сохранения:** `62_save.js` v3 — конверт `{v,sum,at,data}` + FNV-1a + бэкап `.bak` + миграции `2→3`, валидация до мутации. `CFG` (музыка/громкость/рекорды) отдельно.
- **Случайность:** `00_rand.js` mulberry32 `Rand` (0 `Math.random` в `src/game`). Сид от времени, тесты фиксируют сид.
- **Надёжность:** `05_err.js` — журнал 200, `errInstallGlobals`, `FRAME_N`, `loop()` с двумя `try/catch`, 3 сбоя подряд → DOM-аварийное окно с восстановлением/откатом на `#orig`.
