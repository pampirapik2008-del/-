# Пробуждение монстров

Одиночная пиксельная RPG-стратегия в одном HTML-файле: отряд героев, карта миров,
пошагово-реальное сражение, реликвии, магазин и коллекция бойцов.

**`index.html` — это вся игра.** Он открывается двойным щелчком, работает офлайн,
не тянет ни библиотек, ни сетевых ресурсов. Арты, шрифт и звук — внутри файла.

## Как запустить

Просто открыть `index.html` в браузере. Либо локальный сервер:

```bash
python3 -m http.server 8000   # затем http://localhost:8000/
```

## Из чего состоит репозиторий

Игра была одним файлом на 5,7 МБ. Теперь код и ресурсы лежат по отдельности, а
`index.html` собирается из них — **побайтово тем же**, что было раньше.

```
src/game/*.js     код игры (секции, порядок = имя файла)
src/shell.html    HTML-оболочка с метками вставки
src/editor/       загрузчик и встроенный ИИ-редактор
assets/           арты, атлас, шрифт
tools/            сборка, извлечение, golden, fuzz, soak, perf, shots
tests/            обвязка (заглушка DOM), unit-тесты, эталон поведения
docs/             архитектура, решения, формат сейвов, баланс, отчёт, журнал работ
```

Подробности — в `docs/ARCHITECTURE.md`, как добавить героя, реликвию или мир — в `docs/HOWTO.md`,
честный отчёт с цифрами — в `docs/REPORT.md`.

## Команды

```bash
npm run build          # собрать index.html из src/ и assets/
npm run check          # убедиться, что index.html соответствует исходникам
npm run build:dist     # плюс копия в dist/game.html для релиза
npm test               # unit-тесты
npm run golden         # 200 боёв и 500 карт против эталона (~1,5 мин)
npm run golden:record  # перезаписать эталон (осознанно, см. docs/BALANCE.md)
npm run fuzz           # 1000 повреждённых сохранений
npm run soak           # бот играет 20 минут игрового времени (--heap-snapshots DIR пишет снимки кучи для tools/heapdiff.mjs)
npm run perf           # замер времени кадра (--world 3 --depth 9 — тяжёлая волна)
npm run hot            # горячие функции кадра: self/incl мкс за кадр по каждой функции (медианы прогонов)
npm run entry          # блокировки главного потока при входе в каждый мир (критерий ≤ 100 мс)
npm run lint           # статический контроль: неявные глобалы, Math.random, длинные функции, мёртвый код
npm run docs           # перерисовать схему модулей в docs/ARCHITECTURE.md из исходников (tools/modgraph.mjs)
npm run abcmd          # поток команд холста против HEAD: рефакторинг отрисовки не изменил картинку
npm run e2e            # тур по 10 экранам с настоящим холстом против эталона tests/e2e/baseline
npm run shots -- --out /tmp/shots   # 35 скриншотов всех экранов (настоящий canvas, нужен @napi-rs/canvas)
npm run shotdiff -- /tmp/a /tmp/b   # попиксельное сравнение двух наборов снимков
npm run all            # сборка + lint + тесты + fuzz + golden
```

## Что важно знать про поведение

- Баланс, тексты, арты и звук не менялись: эталон бьётся бит в бит.
- Сейвы старого формата (v2) загружаются и автоматически переводятся в v3.
- Сохранение пишется в два слота: если основной повреждён, игра берёт резерв.
- Ошибка в кадре не останавливает игру: цикл переживает сбой, после трёх подряд
  открывается аварийное окно с копированием отчёта и откатом версии.
- Сохранение можно унести файлом: Настройки → «Экспорт» / «Импорт» (работает и там,
  где `localStorage` недоступен).
- Экраны переключает таблица переходов (`Machine`), симуляция идёт фиксированным
  шагом 1/60 с, случайность — один сид (`Rand`): партия воспроизводима.
- Встроенный ИИ-редактор проверяет новую версию кода в песочнице и откатывает её сам,
  если игра не запустилась; панель открывается по паролю разработчика (Настройки →
  «Режим разработчика» или пять касаний левого верхнего угла); в коде только соль и
  хеш PBKDF2-SHA-256, доступ действует до перезагрузки страницы.

## Недостатки, о которых стоит знать

Полный список — в `docs/REPORT.md`, раздел «Известные ограничения». Коротко:
все проверки идут в Node на заглушке холста (реальный FPS телефона и тач не
измерены), ИИ-редактор проверен только в заглушке браузера, JS-куча в свободной
игре колеблется около +5 % за 30 минут из-за JIT V8 (растры кэшей игры ограничены
≈ 14 МБ, данные игры растут < 4 %).
