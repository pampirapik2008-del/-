# План кадров V2

**Статус:** ни один полный комплект не проверен и не подключён; два отдельных кадра прошли предварительную автоматическую проверку. Первые пробы лежат в `assets/generated_candidates/`, это не готовые кадры. Нужно генерировать с образцами, удалять хромакей, нормализовать ближайшим соседом, проверять прозрачные края, положение опоры, полноту силуэта и схожесть с оригиналом. Запасной вариант допустим только по правилам промта после пяти неудачных попыток конкретного кадра, с журналом. Первые для работы: knight, mage, paladin; slime, swamp, red; king.

**Цель для каждого героя:** idle 4, walk 8, run 6, atk 6, hurt 2, dead 4, dodge 4, jump 4, win 4, cast 6, ult 6 (всего 54). Для каждого моба: idle 4, walk 8, atk 6, hurt 2, dead 4, win 4 (28). Босс: idle 4, walk 8, hurt 2, dead 4, win 4 (22), плюс по 6 кадров на каждую разную способность каждой фазы и отдельная обычная атака 6. Разные состояния босса могут требовать разные спрайты. Числа — план, не количество готовых файлов.

## Журнал попыток для первого кадра walk_01

Кандидаты: `assets/generated_candidates/<ключ>/walk_01_attemptN.png`; образцы: `assets/generated_candidates/references/`. Каждый файл получен генератором изображений по своему существующему спрайту. Инструмент создаёт по одному отдельному изображению, а не многокадровый лист. Всего в текущем ходе лимит инструмента — 10 изображений; запросы следующих файлов после лимита завершились ошибкой, не считаются успешными попытками и не дают права на запасной вариант.

| Ключ | Реальные попытки | Результат |
|---|---|---|
| knight | 1, 2 | обе отклонены: спрайт касается края |
| mage | 1, 2 | обе отклонены: спрайт касается края |
| paladin | 1 | нормализован: силуэт 0,839; отклонение цвета 2,25 |
| slime | 1, 2 | 1 обрезан; 2 нормализован: силуэт 0,671; цвет 4,53 |
| swamp | 1 | обрезан; следующий вызов не выполнился из-за лимита |
| red | 1 | обрезан; следующий вызов не выполнился из-за лимита |
| king | 1 | обрезан; следующий вызов не выполнился из-за лимита |

Два предварительных результата: `assets/new_frames/paladin/walk_01.png`, `assets/new_frames/slime/walk_01.png`. `tools/normalize-frame.mjs` удаляет связный хромакей, отбраковывает касание края, масштабирует ближайшим соседом, центрирует и ставит низ ограничивающего прямоугольника на опорную линию; сверяет силуэт (IoU ≥ 0,35) и приближённое расстояние цвета (≤ 60). Это не подтверждает анатомическую точку стопы и сходство личности; нужен визуальный просмотр и доработка валидации, особенно внутренних полостей и крайних поз. Размеры взяты по образцу с двухпиксельным полем. Ни один кадр пока не упакован в атлас и не отображается в игре.

Для повторной проверки: `node tools/normalize-frame.mjs --input assets/generated_candidates/slime/walk_01_attempt2.png --ref assets/generated_candidates/references/slime.png --out assets/new_frames/slime/walk_01.png --width 35 --height 34`. Не менять пороги ради прохождения и не копировать старые кадры вместо генерации.
