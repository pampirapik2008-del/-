# Журнал работ

Формат: время (по сессии) → что сделано → чем проверено → что найдено.

## A. Аудит и базис

**Сделано**

- `tools/extract.mjs` — разовый разбор монолита: HTML-оболочка → `src/shell.html`, загрузчик ИИ-редактора → `src/editor/loader.js`, код игры → `src/game/*.js` (12 секций по маркерам `// ===== NN_name.js =====` плюс голова файла), арты → `assets/img/*.png`, атлас → `assets/atlas.json` (текстом: в нём есть числа вида `46.0`, которые `JSON.stringify` не сохранит), шрифт → `assets/font.woff2`.
- `tools/build.mjs` — сборка `index.html` из частей; `--check` сравнивает с файлом на диске, `--dist` кладёт копию в `dist/`.
- Разделяемая сборка вынесена в `tools/lib/assemble.mjs` (её же использует тестовая обвязка).

**Проверено**

- `node tools/extract.mjs` сам проверяет обратную склейку: код и ресурсы совпадают с исходными секциями байт в байт.
- `node tools/build.mjs --check` → «совпадает», затем полная пересборка и `cmp` с копией файла до разбора → **identical**.
- sha256 собранного файла: `51557e9704dfbc74…` (до любых правок этапа A).
- Размеры: исходный `index.html` 5,44 МБ; `src/editor/loader.js` 1,45 МБ; код игры 313 КБ в 12 файлах; 19 PNG на 2,85 МБ; шрифт 10,7 КБ.

**Найдено**

- Загрузчик ИИ-редактора занимает четверть файла (1,45 МБ) — это отдельный слой, к игре отношения не имеет; при сборке он встраивается последним `<script>`.
- `bakeMap()` (пересборка картинки карты) стоит **~0,89 с** на вызов в headless-прогоне. Вызывается из `newGame()` и `loadGame()` — то есть загрузка сохранения даёт заметный фриз. Кандидат на кэш (этап G).

## B. Детерминированность и golden-эталон

**Сделано**

- `src/game/00_rand.js` — `Rand` (mulberry32) на integer-операциях: `next/seed/int/range/pick/chance/state`.
- Механическая замена **всех 60** обращений `Math.random` в `src/game/*.js` на `Rand` (включая дефолтный параметр `rollRar(…, rnd01 = Math.random)`).
- Сид партии в браузере берётся от времени в `90_boot.js`; тесты выставляют сид сами.
- Тестовая обвязка: `tests/harness/dom.mjs` (заглушка DOM/canvas), `tests/harness/boot.mjs` (запуск игры из `src/` в `node:vm`, управление кадрами, вводом, ожидание загрузки ассетов), `tests/harness/devapi.js` (отладочное API только для тестов, в сборку не попадает).
- `tools/golden.mjs` — запись/сверка эталона: 200 боёв (5 составов, 10 миров, 12 уровней глубины, обычные/боссы/арена/топь) и 500 карт (хеш графа: узлы, рёбра, типы, слои).

**Проверено**

- Эталон записан: бои `297e1dc9a0f961fa` (83 победы / 117 поражений, среднее 1121 кадр), карты `8a1490b024f8b044`.
- Повторный прогон в отдельном процессе: **бои 200 из 200, карты 500 из 500** — совпадение бит в бит.
- `node --check` по каждому файлу `src/game/*.js` — синтаксис чистый; игра поднимается в обвязке с 0 ошибок в консоли.

**Найдено**

- `newGame()` в обвязке занимает ~0,9 с (из них почти всё — `bakeMap`), бой — 0,36 мс на кадр. Тяжёлая часть — пиксельная сборка карты, а не цикл боя.
- Для golden нельзя звать `newGame()` перед каждым боем: 200 боёв × 0,9 с = 3 минуты только на карты. Состояние готовится один раз, перед боем пересеивается генератор.
