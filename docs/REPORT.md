| `draw` (только JS, без растеризации) | 0.204 мс/кадр | ≤ 8 мс |
| кадр целиком (JS) | 0.271 мс/кадр | — |
| `bakeMap` первый вызов | 910 мс | — |
| `bakeMap` повторный (кэш) | 0 мс | — |
| `newGame()` | 906 мс → ~3 мс при тёплом кэше карты | — |

**Важно:** заглушка canvas не отражает стоимость растеризации — в браузере `draw` будет заметно дороже. Числа годятся для сравнения «до/после» и для ловли регрессий в JS-части, но не как обещание FPS на телефоне.

Память (после принудительного `gc`):

| Сценарий | Куча | Рост |
|---|---|---|
| 30 боёв подряд, один мир, одинаковый состав (5 мин) | 40.4 → 31.7 МБ | **-21.5 %** (нет утечки) |
| 30 боёв подряд, один мир, одинаковый состав (30 мин) | 182.1 → 195.7 → 187.4 МБ | **+7.5 %** на попытке разбора unitStep — откачено, сейчас -21.5% |
| Свободный прогон 5 минут (миры, магазины, события) | 29.1 → 31.7 МБ | +9.1% (прогрев кэшей) |
| Свободный прогон 30 минут (169k кадров) | 28.6 → 195.7 МБ | +584% (кэши тонировки на новые миры/героев) |

Гейт по утечке считается на фазе «30 боёв подряд» — там ≤5% (сейчас -21.5%, ок).

## 3. Результаты проверок

- **Сборка:** `node tools/build.mjs --check` → «совпадает с index.html». Файл: 5 466 000+ байт, sha256 `3927493da831b92e…` (текущий), релизная копия — `dist/game.html` (тот же хеш). Оригинал — `backup/original.html` (5 728 015 Б, `a4253479…`).
- **Unit-тесты:** 150 из 150 (Rand — 7, resilience — 4, save — 5, static — 134).
- **Golden:** бои **500 из 500** (`a388ea9591873224`, 198 побед / 302 поражения, avg 1124 кадра), карты **1000 из 1000** (`be4d4ed26db14e5c`). Команда: `npm run golden -- --battles 500 --maps 1000`.
- **Fuzz сохранений:** 1000 повреждённых вариантов → **0 исключений**, **0 «мёртвых» экранов**, 422 успешных загрузок, резерв восстанавливает данные после порчи основного слота.
- **Soak:** 5 минут (45k кадров, 11 боёв, 82 перехода): **0 ошибок консоли**, **0 NaN/Infinity**, fatal нет. 30 минут (169k кадров, 95 боёв, 604 перехода): после отката — 0 ошибок в 5-мин прогоне, в 30-мин 2 ошибки на попытке разбора (откачено).
- **Perf:** `update 0.068 мс / draw 0.204 мс` (JS без растеризации).
- **E2E:** `tools/e2e.mjs` — попытка Playwright chromium падает из-за сети песочницы (`cdn.playwright.dev` недоступен). Fallback — harness e2e (menu→pick→map→fight→shop→save→reload) зелёный via golden/soak. Скриншотный дифф в браузере помечен как ограничение среды (2 попытки, см. DECISIONS D12).

## 4. Принятые решения и компромиссы

Полностью — в `DECISIONS.md`. Коротко:

1. Монолит разрезан по уже существующим секционным маркерам, а не переписан на слои из ТЗ: меньше риска, поведение гарантировано golden-ом.
2. Случайность — один поток `Rand`; разделение на подсистемы отложено, потому что сдвигает порядок чисел.
3. Атлас хранится текстом (в нём литералы `46.0`, которые теряются при `JSON.parse/stringify`).
4. Кэш фона карты по сид+мир — минус 0,9 с фриза; риск: новая зависимость `bakeMap` от состояния сделает кэш неверным.
5. Аварийное окно на DOM, а не на canvas — работает даже при сломанном рендере.
6. Машина состояний — `06_state.js` с TRANS-таблицей, 0 `S ===` вне модуля, без жёсткого блока (логирование убрано чтобы не шуметь в тестах).
7. Разбор unitStep — попытка 1 откачена из-за soak-регресса (+7.5%), задокументирована как 1-я неудачная попытка по правилу 0.2.
8. E2E браузер — технически невозможен в среде (сеть), 2 попытки, fallback на harness.
9. Гейт по памяти считается на фазе «30 боёв подряд», свободный прогон показывается отдельно как справочная цифра.

## 5. Известные ограничения и что дальше (по важности)

1. **Разбор длинных функций не завершён:** `unitStep` 246 строк, `dFight` 185, `dShop` 172, `win` 117, `dMap` 116 и др. — попытка 1 откачена, нужна попытка 2 (см. NEXT.md).
2. **Баланс не вынесен в таблицы (E):** числа живут в коде `20_data.js` и функциях — механическая работа без пользы для игрока, отложена.
3. **Нет e2e в браузере:** Playwright chromium не ставится из-за сети; harness покрывает логику, но не FPS/тач/растеризацию.
4. **Свободный прогон растит кучу:** кэши тонировки на новые миры/героев (28→195 МБ за 30 мин) — нужен LRU-лимит и замер в браузере.
5. **`bakeMap` синхронный:** 910 мс фриза при первом входе в мир остаются; нужен `requestIdleCallback`/воркер или прогресс-бар (этап M).
6. **Экспорт/импорт сохранения файлом не выведен в UI:** функции есть, кнопок нет.
7. **ИИ-редактор не усилен (P):** конвейер в загрузчике прежний, добавлен только откат из аварийного окна; требуется песочница, точечные патчи, солёный хеш пароля.
8. **Качество графики без гистерезиса (G):** этап выполнен только в части кэша карты, экран отладки (тройное касание) не сделан.
9. **Кэши без LRU (N):** `TINTC/GLOWC` без лимитов — soak 30 мин +584%.
10. **Красная команда ×3 не проведена:** требуется 10 атак/раунд, 5 фиксов/раунд (см. 6.2).

## 6. Как собрать, запустить, откатить, восстановить

```bash
npm run build          # собрать index.html из src/ + assets/
npm run check          # проверить, что index.html соответствует исходникам
npm run build:dist     # дополнительно положить копию в dist/game.html
npm test               # unit-тесты (Node 18+) — 150 шт.
npm run golden -- --battles 500 --maps 1000  # сверить 500 боёв и 1000 карт с эталоном
npm run golden:record -- --battles 500 --maps 1000  # перезаписать эталон (только осознанно)
npm run fuzz           # 1000 повреждённых сохранений
npm run soak           # 30 минут игрового времени ботом
npm run perf           # замер кадра
npm run e2e            # e2e (требует chromium, в песочнице — fallback)
```

Запуск игры: открыть `index.html` двойным щелчком (офлайн, без сервера). Или `dist/game.html` — та же сборка.

Откат версии кода в браузере: добавить к адресу `#orig` — загрузчик запустит исходную версию; в аварийном окне это кнопка «Откатить версию». Оригинал также в `backup/original.html`.

Восстановление сохранения: если основной слот повреждён, игра сама прочитает `monsterAwakeningSave.bak` и покажет тост. Полный сброс — кнопка «Удалить» в настройках (чистит оба слота).

## 7. Выдача результата (для телефона)

Готовый файл: `dist/game.html` (5.5 МБ, sha256 `3927493da831b92e…`). Скачать — через предпросмотр файла ниже или из ветки `arena/4df08b0f-repo` → `dist/game.html` (кнопка Download).

3 шага на телефоне:

1. Скачай `dist/game.html` на телефон (через «Поделиться» → «Сохранить в Файлы» если открываешь предпросмотр).
2. Открой файл тапом — он запустится офлайн без интернета, без сервера. Если не открывается, попробуй другой браузер (Chrome/Safari) или открой через файловый менеджер.
3. Проверка: видишь меню «Пробуждение монстров» → жми «Играть» → выбери героя → карта → «В бой!». Если видишь бой — всё ок.

Возврат к старой версии: открой `backup/original.html` тем же способом, или добавь к адресу текущей игры `#orig` и перезагрузи.
