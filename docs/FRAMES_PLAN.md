# План кадров V2

**Статус:** ни один полный комплект и ни один отдельный кадр не приняты и не подключены; один паладин остаётся кандидатом на ручную проверку. Первые пробы лежат в `assets/generated_candidates/`, это не готовые кадры. Нужно генерировать с образцами, удалять хромакей, нормализовать ближайшим соседом, проверять прозрачные края, положение опоры, полноту силуэта и схожесть с оригиналом. Запасной вариант допустим только по правилам промта после пяти неудачных попыток конкретного кадра, с журналом. Первые для работы: knight, mage, paladin; slime, swamp, red; king.

**Уточнение владельца:** одно действие следует генерировать одним многокадровым листом, чтобы фазы сохраняли единство персонажа. Практические размеры листов и шаблон для подходящего генератора — `SPRITE_SHEETS.md`; отделение ячеек не генерирует персонажей. Встроенный генератор доступен только для отдельных изображений и не поддерживает заказ листа; не выдавать собранные из разрозненных генераций кадры за один сгенерированный лист.

**Цель для каждого героя:** idle 4, walk 8, run 6, atk 6, hurt 2, dead 4, dodge 4, jump 4, win 4, cast 6, ult 6 (всего 54). Для каждого моба: idle 4, walk 8, atk 6, hurt 2, dead 4, win 4 (28). Босс: idle 4, walk 8, hurt 2, dead 4, win 4 (22), плюс по 6 кадров на каждую разную способность каждой фазы и отдельная обычная атака 6. Разные состояния босса могут требовать разные спрайты. Числа — план, не количество готовых файлов.

## Журнал попыток

Исходники лежат в `assets/generated_candidates/<ключ>/`, образцы — в `references/`, увеличенные образцы для второй серии — в `references_padded/`. Попытка считается только при реально полученном изображении; отказ по лимиту не считается. Все 20 исходников созданы инструментом генерации изображений. Ключи и последовательные номера не означают готовность. Таблица автоматических метрик и ручного осмотра второй серии и двух прежних нормализаций — `v2-frames-review.json`.

После подписанного сравнения с образцами подозрения о подмене цветов swamp/red **не подтвердились**: ошибка была в неоднозначном порядке показа параллельных изображений. Тем не менее совпадение цвета не подтверждает действия, а метрики пропускают неверное содержимое. Непринятые нормализованные результаты хранятся только в `assets/generated_candidates/normalized/`; папка для готовых кадров намеренно пуста.

`tools/normalize-frame.mjs` удаляет связный и замкнутый хромакей, проверяет конфликт ключа с палитрой образца, отбраковывает касание края, масштабирует ближайшим соседом, центрирует и ставит низ ограничивающего прямоугольника на опорную линию. Проверки IoU ≥ 0,35 и цвета ≤ 60 грубые; метрика изменения — лишь диагностика. Не доказывают личность, правильность позы, истинную точку стопы, отсутствие обводки и непрерывность. Замкнутый хромакей мог быть деталью кандидата, даже если образец не содержит этого цвета. Для каждого выхода обязательны ручной просмотр и проверка последовательности; оставшаяся магентовая обводка на краях ещё не исправлена. Ни один кадр не упакован в атлас и не отображается в игре. Не подменять генерацию кодом и не использовать запасной вариант без пяти реально неудачных попыток конкретного кадра.
